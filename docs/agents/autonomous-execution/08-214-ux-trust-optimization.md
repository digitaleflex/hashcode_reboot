# #214 — UX / Trust / Optimization

## Préconditions

#213 validée.

## Objectif

Optimiser conversion, compréhension et confiance sans dégrader la gouvernance des données.

## Axes

- clarté des étapes ;
- confiance ;
- consentement ;
- feedback ;
- friction ;
- conversion ;
- responsive ;
- accessibilité ;
- performance.

## Méthode

Mesurer avant de modifier. Ne pas introduire de dark patterns. Ne pas collecter de données uniquement pour augmenter une métrique.

## Validation

Tests fonctionnels, accessibilité, performance, funnel et revue de régression.

## Done

Chaque optimisation a une hypothèse, une métrique, une justification et un résultat vérifiable.
