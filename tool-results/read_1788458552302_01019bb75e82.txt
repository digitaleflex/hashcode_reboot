    69→==================================================
    70→

    72→de comprendre rapidement un nouveau membre sans lui donner
    73→l'impression de remplir un long formulaire.

    81→- questions conditionnelles ;
    82→- collecte intelligente ;
    83→- profil généré à la fin ;
    84→- segmentation exploitable ;
    85→- possibilité de rejoindre la communauté officielle WhatsApp
    86→  après validation du parcours.

   642→# 18. LOGIQUE CONDITIONNELLE
   643→==================================================
   644→
   645→Construire un vrai moteur de conditions.
   646→
   647→Exemples :
   648→
   649→IF domain = cybersecurity
   650→→ proposer des sous-domaines cyber.
   651→
   652→IF domain = web
   653→→ proposer des spécialisations web.
   654→
   655→IF domain = ai
   656→→ proposer des spécialisations AI.
   657→
   658→IF mentoring = no
   659→→ ne pas demander budget.
   660→
   661→IF mentoring = maybe
   662→→ questions légères.
   663→
   664→IF mentoring = yes
   665→→ type de mentorat + fréquence + budget.
   666→
   667→IF goal = project
   668→→ demander si le projet existe déjà.
   669→
   670→IF goal = employment
   671→→ demander situation actuelle si pertinent.
   672→
   673→IF goal = entrepreneurship
   674→→ demander stade du projet.
   675→
   676→IF availability < 2h
   677→→ proposer un rythme léger.
   678→
   679→IF availability >= 10h
   680→→ possibilité de proposer parcours plus intensif.
   681→
   682→Le moteur doit être extensible.
   683→
   684→NE PAS coder toutes les conditions en dur dans des composants
   685→UI chaotiques.
   686→
   687→Créer une structure de configuration propre.
   688→
   689→Par exemple :
   690→
   691→questions/
   692→profiling/
   693→rules/
   694→
   695→ou une architecture équivalente adaptée au projet.
